# 🛡️ CyberLab

**CyberLab** is a zero-dependency, browser-based cybersecurity learning playground.

## Features

- 🔐 Password strength lab — checked locally in your browser
- 🎣 Phishing awareness quiz
- #️⃣ SHA-256 Hash Lab using the browser Web Crypto API
- 📋 Personal security checklist
- 🌐 No server, Node.js, Python, database, or external libraries required

## Run

Open **index.html** in a browser, or download/clone the repository.

## Safety

CyberLab is designed for **defensive and educational** use. It does not scan, attack, exploit, or access other people's systems.
